# adt-manager
AtCoder Daily Training (ADT) の参加記録と進捗を管理し、競技プログラミングの効率的な学習をサポートするツールです。

## 開発のきっかけ
日々の学習において、ADTにリアルタイムで参加することが難しいという課題があり、自分のタイミングでバーチャル参加しやすい環境を求めていました。既存の管理ツールも調べましたが、自分の学習スタイルや需要に完全にマッチするものがなかったため、要件を満たすツールを自作することにしました。

## 開発でこだわったポイント
私のプログラミング学習の基本方針である、できない問題に注力し、できるようになるまで取り組むことをシステム上で実現しました。
単なる正解・不正解だけでなく、問題の理解度を細分化してステータス管理できるように設計しています。
ステータスの区分については、既存のAtCoder支援ツール（NoviStepsなど）の優れたUIを参考にしつつ、自身の学習フローに最も合致する以下の4段階を採用しています。

- **未挑戦**: まだ手をつけていない状態
- **挑戦中**: まだ解説を理解できていない、または取り組んでいる最中の状態
- **解説AC**: 解説を読んで理解し、実装できたが、まだ完全に自力では解けない状態
- **AC**: 完全に自力で解けた状態

これにより、挑戦中から解説AC、そして最終的に自力ACへと、自分のペースで着実にステップアップできる学習フローを構築しました。

## 主な機能と工夫した点
- **進捗の可視化**：各問題のステータスを一目で把握できるよう、進捗管理カラムのレイアウトを工夫しました。
- **未完了タスクへのフォーカス**：すでに参加済みの回を非表示にする機能を実装。現在注力すべき「できない問題」にすぐアクセスできるよう、ユーザービリティを高めています。
- **軽量で高速な動作**：HTML/CSS/JavaScriptのみを用いたフロントエンド構成により、ブラウザ上で軽快に動作します。
